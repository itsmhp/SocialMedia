# Independent Validation

This folder stress-tests the product research and concept with a *red-team* approach: look for disconfirming evidence, compare alternatives, then set a test before building the full app.

1. [GPT-5.6 Sol validation: verdict & concept comparison](01-gpt-5.6-sol-validation.md) — *historical:* validated the earlier **meetup** framing.
2. [14-day demand experiment without an app](02-14-day-experiment.md) — the current **chat-first** gate.

> Current decision (Aug 2026): the core is a **fun ephemeral group chat** kept alive by an **extend vote**; real-life meetups are a phase-2 wedge (see [concept/04](../concept/04-rooms-and-lanes.md)). Doc 1 below validated the older meetup framing and is kept as a historical record; the live gate is the chat-first [14-day experiment](02-14-day-experiment.md). The product is only worth building once it clears those thresholds.
