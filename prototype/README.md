# Unggun — Prototipe Klik (tanpa AI)

Prototipe statis yang bisa langsung diklik. **Buka `index.html` di browser** (dobel-klik) — tidak perlu install, tidak perlu internet, tidak ada AI, tidak ada build.

## Yang bisa dicoba

- **Lingkaran:** baca momen teman, bagikan momenmu (pilih mood + tulis), kasih reaksi.
- **Main:** game "Paling mungkin…" — voting antar teman, murni seru-seruan.
- **Ayo Ketemu:** voting waktu nongkrong → **kunci** → jadi beneran (ada reminder).
- **Kenangan:** streak & rekap hangat — tanpa follower, tanpa like publik.

## Sikap (Claude ambil alih)

Bias ke **aksi**: gabungkan **loop campfire yang fun** (momen, reaksi, main bareng) dengan **wedge "rencana jadi"** (Ayo Ketemu). Dibikin dulu biar kerasa, baru ditunjukkan ke orang beneran untuk reaksi. Tetap **100% manusia, tanpa AI**.

## Teknis

HTML + CSS + JS vanilla, tanpa dependency. Semua data hanya contoh (di-seed) dan hidup di memori browser — refresh untuk reset.
